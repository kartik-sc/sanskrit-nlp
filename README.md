# Sanskrit NLP

A reproducible computational corpus analysis project
for Sanskrit natural language processing.

## Phase 1
- Corpus acquisition and preprocessing
- Type-token and frequency analysis
- Vocabulary coverage analysis
- Sentence segmentation
- Word and sentence length analysis
- Comparative linguistic experiments

## Phase 2
- Word embeddings
- Language modelling
- Neural networks
- Named entity recognition

## Data
Language: Sanskrit
Script: Devanagari
Encoding: UTF-8
Primary source: AI4Bharat Sangraha

## Stack
Python, Git, DVC, DagsHub

## Setup
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
dvc pull
